Execução
Instale a extensão do Jupyter
Crie um ambiente python: python3 -m venv [nome_do_seu_ambiente]
Ative o ambiente criado: source [nome_do_seu_ambiente]/bin/activate
Instale os requirements: pip install -r requirements.txt
